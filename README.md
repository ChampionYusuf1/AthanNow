# AthanNow
AthanNow is a Flutter application that calculates current prayer times using your real-time location. Users can choose between different calculation methods (15° or 18°) and various Islamic schools of thought to ensure accurate timing. The app also provides a “Hadith of the Day,” featuring only authentic (sahih) hadith from a public API. Finally, AthanNow offers a built-in Kaaba locator (Qibla compass), helping you easily determine the direction of the Kaaba.
